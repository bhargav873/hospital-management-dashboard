# hospital-management-dashboard(Interactive Dashboard Creation using ms powerBI)

Interactive Power BI dashboard analyzing hospital operations, patient activity, billing performance, and treatment insights through KPI-driven visualizations.

## Objective

To analyze healthcare operational data and generate actionable business insights using Power BI dashboards and analytical reporting techniques.

## Raw Dataseta

The project utilizes multiple relational healthcare datasets, including:

- Patients Data
- Doctors Data
- Appointments Data
- Billing Data
- Treatments Data

## Questions(KPIs)

- Which department records the highest patient admissions?
- What is the average patient stay duration across departments?
- Which doctors handle the highest number of consultations?
- Which treatments generate the highest revenue?
- How do billing trends vary over time?
- What are the peak appointment periods in the hospital?
- Which departments show the highest operational efficiency?
- What is the patient admission-to-discharge ratio?
- Which treatment categories are most frequently utilized?
- How effectively are hospital resources being allocated?
- Which payment methods are most commonly used?
- What trends can be identified in patient visits and appointments?
- Which services contribute most to overall hospital revenue?
- How do treatment costs vary across departments?
- Which operational areas require performance improvement?


## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Process

- Imported and transformed relational healthcare datasets using Power Query.
- Created KPI measures and calculated metrics using DAX.
- Built interactive dashboards and analytical reports.
- Generated operational insights through data visualization.
